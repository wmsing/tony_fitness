# Tony Fitness — 守村保卫

对着摄像头挥剑 / 甩头运动，给友军充能，守卫村庄。

## 玩法

1. 中央是你的村庄，每座建筑都有血条  
2. 敌人会从屏幕边缘缓慢靠近并拆建筑  
3. **左上 = 战士充能**，**右上 = 维修充能**；挥剑 / 甩头给角色充能（不是直接打入侵怪）  
4. **角色血条数字 = 打满后召唤的友方数量**（例如 5 就出 5 个）  
5. 战士自动攻击入侵怪；维修自动修血量最低的建筑  
6. **全部建筑都毁了才失败**（节奏偏慢，鼓励多运动）  
7. 连续充能有连击称号（铁拳 / 风暴 / 传说）；约 2 秒停手会断连  
8. **紧急事件**：危楼冒烟「快修！」/ 精英冲锋「快充战士！」——逼你切换充能优先级  
9. **增益宝箱**：击退 / 召唤攒经验升级；**仅在 10 / 20 / 30… 级**时左下或右下刷出短时宝箱  

绿点 / 绿拳套 = 左手，蓝点 / 蓝拳套 = 右手，黄点 / 「头」= 鼻子。守村模式下手持所选武器。

## 本地启动（必须用 localhost）

摄像头在浏览器里需要安全环境，**不要**直接双击用 `file://` 打开。

```bash
cd /Users/wmsing/Documents/tony_fitness
npx --yes serve .
```

终端里会给出地址（一般是 `http://localhost:3000`），用 Chrome / Edge / Safari 打开即可。

主页打开即进入守村。右上角「菜单」可打开设置（难度 / 武器）。点「开始运动」并允许摄像头权限即可开练。

## 技术说明

- **姿态**：MediaPipe Pose Landmarker（CDN）  
- **打击判定**：手腕 / 头部快速进入充能区才算（慢速挥动不算）  
- **画面**：默认草地地图 + Tiny Swords 贴图；可选摄像头背景  
- **音效**：击中播放 `assets/sound/punch.wav`  
- **BGM**：右上「播放列表」可粘贴 YouTube 播放列表链接或 ID，保存在本机；也可改回默认列表  
- **菜单**：右上「菜单」打开设置；游戏失败可返回再战
