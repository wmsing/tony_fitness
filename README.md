# Tony Fitness — 健身拳击

对着摄像头挥拳 / 甩头运动。首页可选两种模式。

## 模式

### 砸怪健身

1. 站在镜头前，让**上半身**入镜  
2. 角落会出现 1～2 只怪物（位置随机）  
3. **快速挥拳**或**甩头 / 点头**砸入怪物区域（慢速不算）  
4. 打满血条击杀后会再随机补怪  
5. 连击达到 **10 / 20 / 50** 会弹出称号（铁拳 / 风暴 / 传说）

### 守村保卫

1. 中央是你的村庄，每座建筑都有血条  
2. 敌人会从屏幕边缘缓慢靠近并拆建筑  
3. **左上 = 战士充能**，**右上 = 维修充能**；挥拳 / 甩头给角色充能（不是直接打入侵怪）  
4. **角色血条数字 = 打满后召唤的友方数量**（例如 5 就出 5 个）  
5. 战士自动攻击入侵怪；维修自动修血量最低的建筑  
6. **全部建筑都毁了才失败**（节奏偏慢，鼓励多运动）  
7. 连续充能同样有连击称号；约 2 秒停手会断连  
8. **紧急事件**：危楼冒烟「快修！」/ 精英冲锋「快充战士！」——逼你切换充能优先级  
9. **增益宝箱**：击退 / 召唤攒经验升级；**仅在 10 / 20 / 30… 级**时左下或右下刷出短时宝箱。等级大字显示在中央城堡上方。 

绿点 / 绿拳套 = 左手，蓝点 / 蓝拳套 = 右手，黄点 / 「头」= 鼻子。

## 本地启动（必须用 localhost）

摄像头在浏览器里需要安全环境，**不要**直接双击用 `file://` 打开。

```bash
cd /Users/wmsing/Documents/tony_fitness
npx --yes serve .
```

终端里会给出地址（一般是 `http://localhost:3000`），用 Chrome / Edge / Safari 打开即可。

先选模式，再点「开始运动」，允许摄像头权限。右上角「菜单」可返回模式选择。  
主菜单「设置」可调节难度（简单 / 普通 / 困难 / 地狱），影响敌兵密度与砸怪血量，选择会记在本机。

## 技术说明

- 纯静态网页：`index.html` / `styles.css` / `app.js`
- [MediaPipe Pose](https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker)（CDN）跟踪双手腕与鼻尖
- 命中条件：手腕或头部**从目标区域外快速进入区域内** + 短冷却

## 键位 / 操作

无需键盘。用双手挥拳或甩头 / 点头即可。

- **菜单**：选择砸怪或守村；游戏中可点右上「菜单」返回  
- **打开 / 关闭摄像头**：单独开关镜头  
- **地图背景 / 显示画面**：默认 Tiny Swords 草地地图；可切回真实画面  
- **开始运动 / 暂停**：开始或暂停当前模式  
- 底部播放器：歌名 / 歌手、上一首 / 下一首、随机 ↔ 单曲循环；右上角可更换 YouTube 播放列表
